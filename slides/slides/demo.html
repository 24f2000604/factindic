Demo: summarize a document on this laptop

What it takes

  • PDF, Word, text file or pasted text
  • Hindi, Gujarati, Hinglish, Gujlish, English
  • Language and script are detected

What it shows

  • The summary in native script
  • A fact-check score for each sentence
  • All five candidate summaries

Streamlit page, FastAPI service, full pipeline: 6 to 20 seconds for articles up to 350 words.

Start with ./run_app.sh · English is an extension that was not evaluated · only the first 1,000 words are read

Start the app about a minute before the talk; the models need time to load. Use a native Hindi or Gujarati article first, then a Romanized one to show the weak case, and point at the warning. The fact check is automatic and can be wrong in both directions.
