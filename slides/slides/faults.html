Three silent faults, found by reading outputs

A GPU kernel was wrong

PyTorch’s memory-efficient attention gave wrong Gemma-4 results at some text lengths (513, 673 and 1,089 tokens). We switched it off and repeated the whole run.

A score was always zero

The development score computed anchor recall without names, so the choice of prompt would have rested on ROUGE alone.

Hidden end markers

A library padded one baseline’s summaries with end-of-text markers that were never removed.

None of them raised an error. A clean job log is not evidence that the numbers are right.

The Kaggle run was made before these fixes, so it is only a second opinion. The first full laptop run was thrown away after the first fault. The second was caught in the smoke test, when every score came out as exactly zero. The third was caught by reading summaries before that baseline was graded.
